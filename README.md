# amsdias/tap

Homebrew formulae for [Keet](https://github.com/amsdias/Keet), a low-CPU terminal audio player.

```sh
brew install amsdias/tap/keet-player
```

The formula is named `keet-player` because Homebrew's own `keet` is a different app (a chat client). The command it installs is `keet`.

It builds Keet from the release's source code, which takes about a minute. It works on macOS and on Linux.
